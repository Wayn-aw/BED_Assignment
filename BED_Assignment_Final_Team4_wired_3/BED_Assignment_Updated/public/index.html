🔌 Live Backend — All Team Features
Unlike the menu/cart above (static demo data), everything on this tab makes real fetch() calls to the Express + MSSQL API, grouped by feature owner below. Sign in with a demo account first for anything that needs auth.
Not signed in — needed for Rentals & Analytics only
🏠 Rental Agreements /api/v1/rentalsYongsheng
Full CRUD. Create requires an Operator/Admin login above.
❤️ Item Likes /api/v1/likes/:itemIdYongsheng
Toggling a like requires a Patron login above; checking the count is public.
📊 Sales Analytics /api/v1/analytics/sales/:stallIdYongsheng
Operator, Vendor, or Admin login required above.
🇸🇬 NEA Hawker Centres /api/v1/centres/neaYongsheng
Public — proxies live data from data.gov.sg (National Environment Agency). No login needed.
Kyra — Stalls, Feedback & Complaints
Food Stalls /api/v1/stallsKyra
List/view are public. Create requires Operator/Admin login above. Update requires the owning Vendor, or Operator/Admin. Delete requires Operator/Admin.
Feedback /api/v1/feedbackKyra
Submit/edit/delete require a Patron login above. Edit reuses the rating/comments fields — fill them in, then click Edit on a row.
Complaints /api/v1/complaintsKyra
Lodging a complaint / viewing your own history needs a Patron login above; updating status needs Operator/Admin.
Wayne — Menu & Orders
Menu Items /api/v1/menuWayne
Create/update/delete require a Vendor login above, for a stall you own. Cuisine IDs are optional, comma-separated — use List Cuisines below to look them up.
Orders /api/v1/ordersWayne
Checkout works signed in or as a guest. This is a single-item demo order — the real cart above still uses static data. Status updates need a Vendor login above. Order history needs a Patron login above.
Cuisines /api/v1/cuisinesWayne
Public, read-only. These are the CuisineIDs a Vendor can attach to a menu item above.
Jeremiah — Inspections & Promotions
Hygiene Inspections /api/v1/inspectionsJeremiah
Logging, amending, or deleting an inspection requires an NEA Officer login above.
Promotions /api/v1/promotionsJeremiah
Create/edit/delete require a Vendor login above, for a stall you own. Edit reuses the title/discount/dates fields above — fill them in, then click Edit on a row.
Kenneth — Payments
Payments /api/v1/paymentsKenneth
Create/view/update work for any signed-in role. Delete is restricted to Operator/Admin — reversing a payment is a bigger deal than creating one. Simulated gateway — no real charges.
